# Nova Geração Futsal

Site da Associação Atlética Nova Geração, escola de futsal de base em Brasília.

[![Ver site no ar](https://img.shields.io/badge/Ver%20site%20no%20ar-00F5FF?style=for-the-badge&labelColor=0D1117)](https://nova-geracao-futsal.vercel.app) [![Portfólio](https://img.shields.io/badge/Portfólio-FF00E4?style=for-the-badge&labelColor=0D1117)](https://aknoleonel.github.io)

## Sobre o projeto

Site do clube que forma atletas e cidadãos pelo futsal no DF. Apresenta as equipes, a história do clube e os apoiadores, e incentiva a matrícula de novos alunos.

## Destaques

- Faixa animada com patrocinadores e apoiadores
- Contadores animados com números do clube
- Seções de equipes, história e matrícula
- SEO por página com React Helmet

## Tecnologias

React · Vite · Framer Motion · React CountUp · React Helmet

## Rodando localmente

```bash
npm install
npm run dev
```

Para gerar a versão de produção: `npm run build`.
